# ASMR Beauty Pro release checklist

This checklist records the current release status for the **routine, calendar, shelf, reminder, and daily check-in** app, including personalized onboarding and the store-checkout trial transition. The ten-day no-card access was retired for new accounts on October 4; earlier valid leases remain honored. Prior checked items below record historical private-build QA, not the current acquisition path. The deployed controls and remaining security evidence are in [security.md](security.md). The new owner-only candidate also adds optional editorial retailer links in My Shelf. Scan, AI coach, photo journal, product scoring, and commissioned affiliate offers are excluded.
